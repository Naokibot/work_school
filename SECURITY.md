# Security and Privacy

## Data model

Memory is a static GitHub Pages application. Study cards, FSRS state, local settings, and pending review records are stored in the browser's IndexedDB.

The Google Spreadsheet should remain private. The browser talks only to a Google Apps Script Web App. The Apps Script reads the private problem sheet and writes review records to the review sheet while executing as the deploying Google account.

## Secrets

Never commit any of the following to this repository:

- Google account credentials
- OAuth client secrets
- Apps Script `ACCESS_TOKEN`
- cookies or session values
- personal data exports
- JSON backups generated by the application

The spreadsheet ID belongs in Apps Script Script Properties, not in the web application source.

The application's JSON backup intentionally removes `ACCESS_TOKEN` before export.

If a token is exposed, replace `ACCESS_TOKEN` in Apps Script Script Properties immediately and enter the new token in the application settings.

## Recommended GitHub settings

For a public GitHub Pages repository:

- Enable Dependabot alerts and security updates.
- Enable secret scanning and push protection where available.
- Keep Actions workflow permissions at the minimum required level.
- Protect `main` with required pull requests and the CI status check when more than one person contributes.
- Do not store production data, Google Sheets exports, backups, or secrets in Issues, Actions artifacts, or the repository.

## Reporting a security issue

Do not open a public issue containing credentials, tokens, private spreadsheet content, or other personal information. Revoke or rotate an exposed credential first, then contact the repository owner through a private channel.
